    Morning Briefing 개인정보처리방침

    Morning Briefing은 개발자 본인만 사용하는 개인용 도구입니다.

    접근하는 정보

    • Google Calendar 일정 (읽기 전용)
    • Google Tasks 할 일 (읽기 전용)

    사용 목적

    본인의 아침 브리핑 페이지를 만드는 데에만 사용합니다.

    저장과 공유

    • 가져온 정보는 개발자 본인이 관리하는 개인 서버에만 저장되며, 사설 네트워크 안에서만 열람할 수 있습니다.
    • 제3자에게 제공하거나 판매하지 않으며, 광고에 사용하지 않습니다.
    • Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

    접근 해제

    Google 계정 → 보안 → 서드파티 앱 및 서비스에서 언제든지 접근 권한을 해제할 수 있습니다.
